# 赣语 — VoxCPM 适配文件

> 方言组：赣语 | 谱系：赣语·昌靖片
> 生成模型：VoxCPM2 (openbmb/VoxCPM2) — VoxCPM 暂不支持此方言，推荐备选模型：MiniMax / Mureka
> 格式：Control Instruction + Target Text

---

## ⚠️ 备选模型说明

> VoxCPM 暂不支持 **赣语** 的原生合成。推荐使用以下备选 TTS 模型：
>
> **MiniMax / Mureka**
>
> 详见 `TTS_MODEL_GUIDE.md` 第二部分。Control Instruction + Target Text 格式同样适用于备选模型。


## 默认 Control Instruction

```
赣语，中年男性，沉稳语气，正常语速
```

## 完整输入示例

```
(赣语，中年男性，沉稳语气，正常语速)你做么事？咯只东西蛮好喫。你不晓得？莫骗我。
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(赣语，中年男性，沉稳语气，正常语速)你做么事？咯只东西蛮好喫。你不晓得？莫骗我。",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("赣语_voxcpm.wav", wav, model.tts_model.sample_rate)
```

## 词汇注释

么事=什么；咯=这；蛮=很；喫=吃；莫=别

## CLI 调用

```bash
voxcpm design \
  --text "(赣语，中年男性，沉稳语气，正常语速)你做么事？咯只东西蛮好喫。你不晓得？莫骗我。" \
  --output 赣语_voxcpm.wav
```
