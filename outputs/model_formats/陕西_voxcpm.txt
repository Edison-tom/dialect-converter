# 陕西话 — VoxCPM 适配文件

> 方言组：陕西话 | 谱系：中原官话·关中片
> 生成模型：VoxCPM2 (openbmb/VoxCPM2)
> 格式：Control Instruction + Target Text

---

## 默认 Control Instruction

```
陕西话，中年男性，低沉嗓音，语速偏慢
```

## 完整输入示例

```
(陕西话，中年男性，低沉嗓音，语速偏慢)你弄啥哩？这东西嫽滴很。你不得知道？包哄我。
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(陕西话，中年男性，低沉嗓音，语速偏慢)你弄啥哩？这东西嫽滴很。你不得知道？包哄我。",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("陕西_voxcpm.wav", wav, model.tts_model.sample_rate)
```

## 词汇注释

弄啥=干什么；嫽滴很=很好；不得=不；包=别；哄=骗

## CLI 调用

```bash
voxcpm design \
  --text "(陕西话，中年男性，低沉嗓音，语速偏慢)你弄啥哩？这东西嫽滴很。你不得知道？包哄我。" \
  --output 陕西_voxcpm.wav
```
