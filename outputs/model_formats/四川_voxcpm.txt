# 四川话 — VoxCPM 适配文件

> 方言组：四川话 | 谱系：西南官话·成渝片
> 生成模型：VoxCPM2 (openbmb/VoxCPM2)
> 格式：Control Instruction + Target Text

---

## 默认 Control Instruction

```
A middle-aged Sichuan male, relaxed and lazy tone, slightly slow pace, with Chengdu accent, trailing particles
```

## 完整输入示例

```
(A middle-aged Sichuan male, relaxed and lazy tone, slightly slow pace, with Chengdu accent, trailing particles)你在搞爪子？这个硬是好吃得很。你不晓得嗦？莫日弄老子哈。
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(A middle-aged Sichuan male, relaxed and lazy tone, slightly slow pace, with Chengdu accent, trailing particles)你在搞爪子？这个硬是好吃得很。你不晓得嗦？莫日弄老子哈。",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("四川_voxcpm.wav", wav, model.tts_model.sample_rate)
```

## 词汇注释

爪子=什么；硬是=真的很；日弄=骗/忽悠；要得=可以；巴适=舒服/好

## CLI 调用

```bash
voxcpm design \
  --text "(A middle-aged Sichuan male, relaxed and lazy tone, slightly slow pace, with Chengdu accent, trailing particles)你在搞爪子？这个硬是好吃得很。你不晓得嗦？莫日弄老子哈。" \
  --output 四川_voxcpm.wav
```
