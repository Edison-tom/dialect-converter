# 山东话 — VoxCPM 适配文件

> 方言组：山东话 | 谱系：冀鲁/胶辽官话
> 生成模型：VoxCPM2 (openbmb/VoxCPM2)
> 格式：Control Instruction + Target Text

---

## 默认 Control Instruction

```
A middle-aged Shandong male, robust and straightforward voice, moderate pace, with Ji-Lu accent, bold delivery
```

## 完整输入示例

```
(A middle-aged Shandong male, robust and straightforward voice, moderate pace, with Ji-Lu accent, bold delivery)你干啥呢？这玩意儿杠好吃。你不知道啊？别忽悠俺了。
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(A middle-aged Shandong male, robust and straightforward voice, moderate pace, with Ji-Lu accent, bold delivery)你干啥呢？这玩意儿杠好吃。你不知道啊？别忽悠俺了。",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("山东_voxcpm.wav", wav, model.tts_model.sample_rate)
```

## 词汇注释

干啥=干什么；杠=非常；俺=我/我们；忽悠=骗

## CLI 调用

```bash
voxcpm design \
  --text "(A middle-aged Shandong male, robust and straightforward voice, moderate pace, with Ji-Lu accent, bold delivery)你干啥呢？这玩意儿杠好吃。你不知道啊？别忽悠俺了。" \
  --output 山东_voxcpm.wav
```
