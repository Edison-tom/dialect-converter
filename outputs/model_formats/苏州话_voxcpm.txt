# 苏州话 — VoxCPM 适配文件

> 方言组：吴语（分支） | 谱系：吴语·太湖片
> 生成模型：VoxCPM2 (openbmb/VoxCPM2)
> 格式：Control Instruction + Target Text

---

## 默认 Control Instruction

```
A young Shanghai female, gentle and soft voice, moderate pace, with Wu dialect accent, melodic rising tones
```

## 完整输入示例

```
(A young Shanghai female, gentle and soft voice, moderate pace, with Wu dialect accent, melodic rising tones)灶下间
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(A young Shanghai female, gentle and soft voice, moderate pace, with Wu dialect accent, melodic rising tones)灶下间",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("苏州话_voxcpm.wav", wav, model.tts_model.sample_rate)
```
