# 济南话 — VoxCPM 适配文件

> 方言组：山东话（分支） | 谱系：冀鲁官话
> 生成模型：VoxCPM2 (openbmb/VoxCPM2)
> 格式：Control Instruction + Target Text

---

## 默认 Control Instruction

```
A middle-aged Shandong male, robust and straightforward voice, moderate pace, with Ji-Lu accent, bold delivery
```

## 完整输入示例

```
(A middle-aged Shandong male, robust and straightforward voice, moderate pace, with Ji-Lu accent, bold delivery)短视频
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(A middle-aged Shandong male, robust and straightforward voice, moderate pace, with Ji-Lu accent, bold delivery)短视频",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("济南话_voxcpm.wav", wav, model.tts_model.sample_rate)
```
