# 客家话 — VoxCPM 适配文件

> 方言组：客家话 | 谱系：客语·粤台片
> 生成模型：VoxCPM2 (openbmb/VoxCPM2) — VoxCPM 暂不支持此方言，推荐备选模型：Seed Audio / Mureka
> 格式：Control Instruction + Target Text

---

## ⚠️ 备选模型说明

> VoxCPM 暂不支持 **客家话** 的原生合成。推荐使用以下备选 TTS 模型：
>
> **Seed Audio / Mureka**
>
> 详见 `TTS_MODEL_GUIDE.md` 第二部分。Control Instruction + Target Text 格式同样适用于备选模型。


## 默认 Control Instruction

```
客家话，中年男性，温和语气，正常语速
```

## 完整输入示例

```
(客家话，中年男性，温和语气，正常语速)你做么个？这东西当好食。你毋知？莫骗捱。
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(客家话，中年男性，温和语气，正常语速)你做么个？这东西当好食。你毋知？莫骗捱。",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("客家话_voxcpm.wav", wav, model.tts_model.sample_rate)
```

## 词汇注释

么个=什么；当=很；食=吃；毋=不；捱=我

## CLI 调用

```bash
voxcpm design \
  --text "(客家话，中年男性，温和语气，正常语速)你做么个？这东西当好食。你毋知？莫骗捱。" \
  --output 客家话_voxcpm.wav
```
