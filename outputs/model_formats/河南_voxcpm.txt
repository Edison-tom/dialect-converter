# 河南话 — VoxCPM 适配文件

> 方言组：河南话 | 谱系：中原官话·郑开片
> 生成模型：VoxCPM2 (openbmb/VoxCPM2)
> 格式：Control Instruction + Target Text

---

## 默认 Control Instruction

```
河南话，中年男性，沉稳语气，正常语速
```

## 完整输入示例

```
(河南话，中年男性，沉稳语气，正常语速)你弄啥嘞？这东西可中可好吃。你不知情哩？白搁这儿骗我。
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(河南话，中年男性，沉稳语气，正常语速)你弄啥嘞？这东西可中可好吃。你不知情哩？白搁这儿骗我。",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("河南_voxcpm.wav", wav, model.tts_model.sample_rate)
```

## 词汇注释

弄啥=干什么；中=行/好；可=很；白=别；搁=在

## CLI 调用

```bash
voxcpm design \
  --text "(河南话，中年男性，沉稳语气，正常语速)你弄啥嘞？这东西可中可好吃。你不知情哩？白搁这儿骗我。" \
  --output 河南_voxcpm.wav
```
