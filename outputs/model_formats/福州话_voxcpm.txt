# 福州话 — VoxCPM 适配文件

> 方言组：福州话 | 谱系：闽语·闽东片
> 生成模型：VoxCPM2 (openbmb/VoxCPM2) — VoxCPM 暂不支持此方言，推荐备选模型：Seed Audio / Mureka
> 格式：Control Instruction + Target Text

---

## ⚠️ 备选模型说明

> VoxCPM 暂不支持 **福州话** 的原生合成。推荐使用以下备选 TTS 模型：
>
> **Seed Audio / Mureka**
>
> 详见 `TTS_MODEL_GUIDE.md` 第二部分。Control Instruction + Target Text 格式同样适用于备选模型。


## 默认 Control Instruction

```
福州话，中年男性，温和语气，语速偏慢
```

## 完整输入示例

```
(福州话，中年男性，温和语气，语速偏慢)汝做什乇？这物件野好食。汝伓知？莫骗我。
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(福州话，中年男性，温和语气，语速偏慢)汝做什乇？这物件野好食。汝伓知？莫骗我。",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("福州话_voxcpm.wav", wav, model.tts_model.sample_rate)
```

## 词汇注释

汝=你；什乇=什么；物件=东西；野=很；伓=不；莫=别

## CLI 调用

```bash
voxcpm design \
  --text "(福州话，中年男性，温和语气，语速偏慢)汝做什乇？这物件野好食。汝伓知？莫骗我。" \
  --output 福州话_voxcpm.wav
```
