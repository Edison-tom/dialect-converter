# 贵阳话 — VoxCPM 适配文件

> 方言组：四川话（分支） | 谱系：西南官话·黔中片
> 生成模型：VoxCPM2 (openbmb/VoxCPM2)
> 格式：Control Instruction + Target Text

---

## 默认 Control Instruction

```
四川方言，中年男性，慵懒语气，语速偏慢
```

## 完整输入示例

```
(四川方言，中年男性，慵懒语气，语速偏慢)灶房
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(四川方言，中年男性，慵懒语气，语速偏慢)灶房",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("贵阳话_voxcpm.wav", wav, model.tts_model.sample_rate)
```
