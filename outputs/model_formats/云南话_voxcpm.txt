# 云南话 — VoxCPM 适配文件

> 方言组：四川话（分支） | 谱系：西南官话·滇中片
> 生成模型：VoxCPM2 (openbmb/VoxCPM2)
> 格式：Control Instruction + Target Text

---

## 默认 Control Instruction

```
A middle-aged Sichuan male, relaxed and lazy tone, slightly slow pace, with Chengdu accent, trailing particles
```

## 完整输入示例

```
(A middle-aged Sichuan male, relaxed and lazy tone, slightly slow pace, with Chengdu accent, trailing particles)打雷
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(A middle-aged Sichuan male, relaxed and lazy tone, slightly slow pace, with Chengdu accent, trailing particles)打雷",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("云南话_voxcpm.wav", wav, model.tts_model.sample_rate)
```
