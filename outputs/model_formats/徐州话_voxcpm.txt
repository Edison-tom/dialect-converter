# 徐州话 — VoxCPM 适配文件

> 方言组：河南话（分支） | 谱系：中原官话·徐淮片
> 生成模型：VoxCPM2 (openbmb/VoxCPM2)
> 格式：Control Instruction + Target Text

---

## 默认 Control Instruction

```
A middle-aged Henan male, steady and grounded tone, moderate pace, with Central Plains accent, nasal quality
```

## 完整输入示例

```
(A middle-aged Henan male, steady and grounded tone, moderate pace, with Central Plains accent, nasal quality)锅屋
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(A middle-aged Henan male, steady and grounded tone, moderate pace, with Central Plains accent, nasal quality)锅屋",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("徐州话_voxcpm.wav", wav, model.tts_model.sample_rate)
```
