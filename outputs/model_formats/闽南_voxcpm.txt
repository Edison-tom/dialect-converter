# 闽南话 — VoxCPM 适配文件

> 方言组：闽南话 | 谱系：闽语·闽南片
> 生成模型：VoxCPM2 (openbmb/VoxCPM2)
> 格式：Control Instruction + Target Text

---

## 默认 Control Instruction

```
A middle-aged Minnan male, warm and friendly voice, slow pace, with Southern Fujian accent, soft trailing tones
```

## 完整输入示例

```
(A middle-aged Minnan male, warm and friendly voice, slow pace, with Southern Fujian accent, soft trailing tones)汝咧做啥物？这物事诚好食。汝毋知影？莫骗我。
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(A middle-aged Minnan male, warm and friendly voice, slow pace, with Southern Fujian accent, soft trailing tones)汝咧做啥物？这物事诚好食。汝毋知影？莫骗我。",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("闽南_voxcpm.wav", wav, model.tts_model.sample_rate)
```

## 词汇注释

汝=你；啥物=什么；物事=东西；诚=很；毋=不；莫=别

## CLI 调用

```bash
voxcpm design \
  --text "(A middle-aged Minnan male, warm and friendly voice, slow pace, with Southern Fujian accent, soft trailing tones)汝咧做啥物？这物事诚好食。汝毋知影？莫骗我。" \
  --output 闽南_voxcpm.wav
```
