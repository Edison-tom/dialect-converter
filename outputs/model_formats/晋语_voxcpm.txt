# 晋语 — VoxCPM 适配文件

> 方言组：晋语 | 谱系：晋语·并州片
> 生成模型：VoxCPM2 (openbmb/VoxCPM2) — VoxCPM 暂不支持此方言，推荐备选模型：Seed Audio / MiniMax
> 格式：Control Instruction + Target Text

---

## ⚠️ 备选模型说明

> VoxCPM 暂不支持 **晋语** 的原生合成。推荐使用以下备选 TTS 模型：
>
> **Seed Audio / MiniMax**
>
> 详见 `TTS_MODEL_GUIDE.md` 第二部分。Control Instruction + Target Text 格式同样适用于备选模型。


## 默认 Control Instruction

```
晋语，中年男性，低沉嗓音，语速偏慢
```

## 完整输入示例

```
(晋语，中年男性，低沉嗓音，语速偏慢)你做啥咧？这东西可好吃了。你不知道？别哄我。
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(晋语，中年男性，低沉嗓音，语速偏慢)你做啥咧？这东西可好吃了。你不知道？别哄我。",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("晋语_voxcpm.wav", wav, model.tts_model.sample_rate)
```

## 词汇注释

做啥=干什么；咧=语气词；可=很；哄=骗

## CLI 调用

```bash
voxcpm design \
  --text "(晋语，中年男性，低沉嗓音，语速偏慢)你做啥咧？这东西可好吃了。你不知道？别哄我。" \
  --output 晋语_voxcpm.wav
```
