# 兰州话 — VoxCPM 适配文件

> 方言组：兰州话 | 谱系：兰银官话·金城片
> 生成模型：VoxCPM2 (openbmb/VoxCPM2) — VoxCPM 暂不支持此方言，推荐备选模型：MiniMax / Seed Audio
> 格式：Control Instruction + Target Text

---

## ⚠️ 备选模型说明

> VoxCPM 暂不支持 **兰州话** 的原生合成。推荐使用以下备选 TTS 模型：
>
> **MiniMax / Seed Audio**
>
> 详见 `TTS_MODEL_GUIDE.md` 第二部分。Control Instruction + Target Text 格式同样适用于备选模型。


## 默认 Control Instruction

```
兰州话，中年男性，豪爽语气，正常语速
```

## 完整输入示例

```
(兰州话，中年男性，豪爽语气，正常语速)你做啥呢？这东西满好滴。你不知道？白骗我。
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(兰州话，中年男性，豪爽语气，正常语速)你做啥呢？这东西满好滴。你不知道？白骗我。",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("兰州话_voxcpm.wav", wav, model.tts_model.sample_rate)
```

## 词汇注释

做啥=干什么；满=很；滴=语气词；白=别

## CLI 调用

```bash
voxcpm design \
  --text "(兰州话，中年男性，豪爽语气，正常语速)你做啥呢？这东西满好滴。你不知道？白骗我。" \
  --output 兰州话_voxcpm.wav
```
