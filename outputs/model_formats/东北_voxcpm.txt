# 东北话 — VoxCPM 适配文件

> 方言组：东北话 | 谱系：东北官话
> 生成模型：VoxCPM2 (openbmb/VoxCPM2)
> 格式：Control Instruction + Target Text

---

## 默认 Control Instruction

```
东北话，中年男性，洪亮嗓音，语速较快
```

## 完整输入示例

```
(东北话，中年男性，洪亮嗓音，语速较快)你嘎哈呢？这玩意儿嘎嘎好吃。你不知道啊？别忽悠我了。
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(东北话，中年男性，洪亮嗓音，语速较快)你嘎哈呢？这玩意儿嘎嘎好吃。你不知道啊？别忽悠我了。",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("东北_voxcpm.wav", wav, model.tts_model.sample_rate)
```

## 词汇注释

嘎哈=干什么；玩意儿=东西；嘎嘎=非常；忽悠=骗

## CLI 调用

```bash
voxcpm design \
  --text "(东北话，中年男性，洪亮嗓音，语速较快)你嘎哈呢？这玩意儿嘎嘎好吃。你不知道啊？别忽悠我了。" \
  --output 东北_voxcpm.wav
```
