# 天津话 — VoxCPM 适配文件

> 方言组：天津话 | 谱系：冀鲁官话·天津片
> 生成模型：VoxCPM2 (openbmb/VoxCPM2)
> 格式：Control Instruction + Target Text

---

## 默认 Control Instruction

```
天津话，中年男性，幽默语气，正常语速
```

## 完整输入示例

```
(天津话，中年男性，幽默语气，正常语速)你干嘛呢？介玩意儿倍儿好吃。你不儿道啊？甭忽悠我了。
```

## Python 调用示例

```python
from voxcpm import VoxCPM
import soundfile as sf

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)

wav = model.generate(
    text="(天津话，中年男性，幽默语气，正常语速)你干嘛呢？介玩意儿倍儿好吃。你不儿道啊？甭忽悠我了。",
    cfg_value=2.0,
    inference_timesteps=10,
    seed=42,
)
sf.write("天津_voxcpm.wav", wav, model.tts_model.sample_rate)
```

## 词汇注释

干嘛=干什么；介=这；倍儿=非常；不儿道=不知道；甭=别

## CLI 调用

```bash
voxcpm design \
  --text "(天津话，中年男性，幽默语气，正常语速)你干嘛呢？介玩意儿倍儿好吃。你不儿道啊？甭忽悠我了。" \
  --output 天津_voxcpm.wav
```
